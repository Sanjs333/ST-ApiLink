# API链接管理

用于管理 SillyTavern 的 API 连接方案、密钥和模型，无需安装配套服务端插件。

## 主要功能

- **连接方案**：新建、编辑和切换方案，支持搜索、分组、批量复制和删除。切换时提示保存未提交的修改。
- **密钥管理**：分类搜索、查看方案引用、重命名、批量清理及重复密钥合并。
- **模型选择**：拉取模型列表或手动填写模型 ID，支持搜索与分组。
- **附加参数预设**：保存和复用 Custom 连接的附加请求头、请求体及排除字段。

## 使用

打开酒馆的 **API 设置页**：

- **方案栏加号**：新建空白连接，填写后保存。
- **方案栏文件夹**：管理已保存方案，点击方案行切换连接。
- **密钥输入框旁的钥匙**：管理或选择密钥。

## 注意事项

- Vertex AI 使用酒馆内置或已保存的模型列表，也可通过“自定义模型”手动添加模型 ID。
- 重复密钥识别需在酒馆 `config.yaml` 中启用 `allowKeysExposure: true`，并重启酒馆。日常密钥管理无需开启。
- 删除方案时，未被其他方案引用的密钥默认一并清理，可取消勾选以保留。已删除的密钥无法恢复。
